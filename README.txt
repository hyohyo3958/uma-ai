# UMA AI PWAスターター

## 公開するファイル
このフォルダの中身（`index.html`、`manifest.webmanifest`、`sw.js`、`icons`）を、GitHubリポジトリの一番上にアップロードしてください。

## iPhoneで使う
1. 公開後の `https://...github.io/.../` をiPhoneのSafariで開く
2. 共有ボタンを押す
3. 「ホーム画面に追加」を選ぶ
4. 「Webアプリとして開く」が表示されたらオンにして「追加」

## 注意
- この版は画面操作とCSV取り込みの試作品です。
- JRAの出走表・オッズを自動取得する機能や、本物のAI予想はまだ接続されていません。
- 実データ連携は、データ提供元の利用条件を確認してから追加します。
